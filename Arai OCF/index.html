Section 1: First part of the definition

In what follows, \(\Omega\) denotes the least recursively regular ordinal \(\omega_1^{CK}\),
and \(\psi_\Omega\) is a collapsing function such that \(\psi_\Omega(\alpha)\lt\Omega\).
\(\mathbb{I}_N\) is an ordinal term denoting an ordinal such that \(L_{\mathbb{I}_N} = \mathbb{KP}\omega+\Pi_N\text{-Collection}+(V = L)\).
We work in a set theory \(\mathrm{ZFC}\) (\(\{St_i\}_i\)), where each \(St_i\) (\(0\lt i\lte N\)) is a unary predicate symbol.
Let \(St_0\) denote the set of uncountable cardinal less than \(\mathbb{I}_N\).
\(\Omega\) and \(\mathbb{I}_N\) are strongly critical numbers with \(\Omega\lt\mathbb{I}_N\),
i.e., non-zero ordinals closed under the binary Veblen function \(\varphi\alpha\beta = \varphi_\alpha(\beta)\).
We assume \(St_{i+1}\subset St_i\) for \(i\lt N\),
each \(St_i\) is an unbounded class of ordinals less than \(\mathbb{I}_N\) whose minimal element is greater than \(\Omega\)
i.e., \(\Omega\lt\mathrm{min}\left(\cup_{0\lt i\lte N} St_i\right)\).
The predicate \(St_i\) is identified with the calss \(\{\alpha\in\mathrm{Ord}|\alpha\in St_i\}\).
For \(\alpha\lt\mathbb{I}_N\), \(\alpha^{\dagger i}\) denotes the least ordinal in the class \(St_i\) greater than \alpha.
If \(\alpha\gte\mathbb{I}_N\), let \(\alpha^{\dagger i} := \mathbb{I}_N\).
