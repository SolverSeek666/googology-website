Primitive Array Notation

[PrAN]

Limit: \(f_{\omega+1}\left( n \right)\)

Definitions

let A be any array
R1: Ska,b(0) = ab
R2: Ska,1(A) = a
R3: Ska,b(c) = Ska,Ska,b-1(c)(c-1)

Examples

Example 1:
Sk3,3(0) = 9
Example 2:
Sk3,3(1) =
Sk3,Sk3,2(1)(0) =
Sk3,Sk3,Sk3,1(1)(0)(0) =
Sk3,Sk3,3(0)(0) =
Sk3,9(0) = 27
Example 3:
Sk3,3(2) =
Sk3,Sk3,2(2)(1) =
Sk3,Sk3,Sk3,1(2)(1)(1) =
Sk3,Sk3,3(1)(1) =
Sk3,27(1) = 327

Linear Array Notation

[LAN]

Limit: \(f_{\omega^\omega}\left( n \right)\)

Definitions

let A be any array
R1: Ska,b(0) = ab
R2: Ska,1(A) = a
R3: Ska,b(A,0) = Ska,b(A)
R4: Ska,b(c,A) = Ska,Ska,b-1(c,A)(c-1,A)

If none of the first 3 rules above applies, start from the 1st entry in the array and start the process below.

C1: if the entry > 0, repeat after R4.
C2: if the entry = 0, then jump to the next entry.
 C2.1: if the entry > 0, then
  1. Decrease the number by 1.
  2. Change the previous number to iterator.
  3. Replace the iterator to base.
  4. The process ends.
 C2.2: if the entry = 0, repeat after C2.

Examples

Example 1:
not now.

Extended Array Notation

[exAN]

Limit: \(f_{\omega^\omega+1}\left( n \right)\)

Definitions

let A be any array
R1: Ska,b(0) = ab
R2: Ska,1(A) = a
R3: Ska,b(A Sep 0) = Ska,b(A Sep 0)
R4: Ska,b(c Sep A) = Ska,Ska,b-1(c Sep A)(c-1 Sep A)

If none of the first 3 rules above applies, start from the 1st number in the array and start the process below.

C1: if the number > 0, repeat after R4.
C2: if the number = 0, look at the separator after the number.
 C2.1: if the separator is the form {n}, do the process below.
  C2.1.1: if n > 1, then
   1. Decrease n by 1.
   2. Add ",0" in front of the separator.
   3. The process ends.
  C2.1.2: if n = 1, then
   1. Change the separator into ",".
   2. The process ends.
 C2.2: otherwise, move on to the next number.
  C2.2.1: if the entry > 0, then
   1. Decrease the number by 1.
   2. Change the previous number to iterator.
   3. Replace the iterator to base.
   4. The process ends.
  C2.2.2: if the number = 0, repeat after C2.

Examples

Example 1:
not now.

Expanding Array Notation

[EAN]

Limit: \(f_{\varphi\left( \omega,0 \right)}\left( n \right)\)

Definitions

let A be any array
let Sep be any separator
R1: Ska,b(0) = ab
R2: Ska,1(A) = a
R3: Ska,b(A Sep 0) = Ska,b(A Sep 0)
R4: Ska,b(c Sep A) = Ska,Ska,b-1(c Sep A)(c-1 Sep A)

If none of the first 3 rules above applies, start from the 1st number in the array and start the process below.

C1: if the number > 0, repeat after R4.
C2: if the number = 0, look at the separator after the number.
 C2.1: if the separator is the form {n Sep A}, do the process below.
  C2.1.1: if A > 0, do the process below.
   C2.1.1.1: if n > 0, then
    1. Decrease n by 1.
    2. Add ",0" in front of the separator.
    3. The process ends.
   C2.1.1.2: if n = 0, do the process below.
    C2.1.1.2.1: if Sep is the form ",,", then
     1. decrease the first number of A by 1.
     2. Copy the separator and the numbers next to it.
     3. then paste it on n and repeat it iterator times.
     4. replace the iterator to base.
     5. the process ends.
    C2.1.1.2.2: otherwise, focus on A in the separator and repeat after C2.
  C2.1.2: if A = 0, do the process below.
   C2.1.2.1: if n > 1, then
    1. Decrease n by 1.
    2. Add ",0" in front of the separator.
    3. The process ends.
   C2.1.2.2: if n = 1, then
    1. Change the separator into ",".
    2. The process ends.
 C2.2: otherwise, move on to the next number, and do the process below.
  C2.2.1: if the number > 0, then
   1. Decrease the number by 1.
   2. Change the previous number to iterator.
   3. Replace the iterator to base.
   4. The process ends.
  C2.2.2: if the number = 0, repeat after C2.
