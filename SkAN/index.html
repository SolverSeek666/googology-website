Primitive Array Notation

[PrAN]

Limit: \(f_{\omega+1}\left( n \right)\)

Definitions

let A be any array
R1: Ska,b(0) = ab
R2: Ska,1(A) = a
R3: Ska,b(c) = Ska,Ska,b-1(c)(c-1)

Examples

Example 1:
Sk3,3(0) = 9
Example 2:
Sk3,3(1) =
Sk3,Sk3,2(1)(0) =
Sk3,Sk3,Sk3,1(1)(0)(0) =
Sk3,Sk3,3(0)(0) =
Sk3,9(0) = 27
Example 3:
Sk3,3(2) =
Sk3,Sk3,2(2)(1) =
Sk3,Sk3,Sk3,1(2)(1)(1) =
Sk3,Sk3,3(1)(1) =
Sk3,27(1) = 327

Linear Array Notation

[LAN]

Limit: \(f_{\omega^\omega}\left( n \right)\)

Definitions

let A be any array
R1: Ska,b(0) = ab
R2: Ska,1(A) = a
R3: Ska,b(A,0) = Ska,b(A)
R4: Ska,b(c) = Ska,Ska,b-1(c)(c-1)

if the number of the first 3 rule applies, find the first number in the array and start the process below.

C1: if the number > 0, repeat after R4. the process ends.
C2: if the number = 0, move to the next number and do the process below.
 C2.1: if the number > 0, decrease the number by 1, then change the previous number to iterator, replace the iterator to base. the process ends.
 C2.2: if the number = 0, repeat after C2.

Examples

Extended Array Notation

[exAN]

Limit: \(f_{\omega^\omega+1}\left( n \right)\)

Definitions

let A be any array
R1: Ska,b(0) = ab
R2: Ska,1(A) = a
R3: Ska,b(A Sep 0) = Ska,b(A Sep 0)
R4: Ska,b(c Sep A) = Ska,Ska,b-1(c Sep A)(c-1 Sep A)

if the number of the first 3 rule applies, find the first number in the array and start the process below.

C1: if the number > 0, repeat after R4. the process ends.
C2: if the number = 0, look at the separator after the number.
 C2.1: if the separator is the form {n}, do the process below.
  C2.1.1: if n > 1, decrease n by 1, and add ",0" in front of the separator. the process ends.
  C2.1.2: if n = 1, change the separator into ",". the process ends.
 C2.2: otherwise, move on to the next number, and do the process below.
  C2.2.1: if the number > 0, decrease the number by 1, then change the previous number to iterator, replace the iterator to base. the process ends.
  C2.2.2: if the number = 0, repeat after C2.

Examples

R2: Ska,1(A) = a
R3: Ska,b(A Sep 0) = Ska,b(A Sep 0)
R4: Ska,b(c Sep A) = Ska,Ska,b-1(c Sep A)(c-1 Sep A)

if the number of the first 3 rule applies, find the first number in the array and start the process below.

C1: if the number > 0, repeat after R4. the process ends.
C2: if the number = 0, look at the separator after the number.
 C2.1: if the separator is the form {n Sep A}, do the process below.

   C2.1.1.1: if n > 0, decrease n by 1, and add ",0" in front of the separator. the process ends.
   C2.1.1.2: if n = 0, focus on the array in the separator, repeat after C2.
  C2.1.2: if A = 0, do the process below.
   C2.1.2.1: if n > 1, decrease n by 1, and add ",0" in front of the separator. the process ends.
