Chapter 1: The genesis

Limit: \(\varepsilon_0\)

$$C_0(\alpha,\beta)=\{0\}\cup\beta$$ $$\qquad\qquad\quad\;\; C_{n+1}(\alpha,\beta)=\{\gamma+\delta|\gamma,\delta\in C_n(\alpha,\beta)\}$$ $$\qquad\qquad\qquad\qquad\qquad\qquad\;\;\; \cup\;\{\psi(\gamma)|\gamma\in C_n(\alpha,\beta)\land\gamma\lt\alpha\}$$ $$\qquad\; C(\alpha,\beta)=\bigcup_{n\lt\omega} C_n(\alpha,\beta)$$ $$\qquad\qquad\qquad\qquad\qquad\;\,\, \psi(\alpha)=\min\{\beta\lt\Omega|C(\alpha,\beta)\cap\Omega\subseteq\beta\}$$
This is the beginning of the OCF.
A lot of things in this OCF is made up using set theory and a little bit logic. Don't worry about that, I'll explain to you now.

Introduction to set theory

so first thing we learn in set theory is a set. If a set contains contains something, we note the set as: $$\{\mathrm{something}\}$$ For example, If a set contains number 1, 2, 3, 5, 7, 10, or even transfinite number like \(\omega\), the set is noted as: $$\{1, 2, 3, 5, 7, 10, \omega\}$$ But what if there's a set that cotains all the NATURAL numbers? Well, we note this as: $$\mathbb{N}=\{n|n\in\mathbb{N}\}$$
